# ⚡ LeetCode Complexity Insight

An AI-powered Chrome extension that analyzes your LeetCode submissions and provides instant insights into **time complexity, space complexity, algorithmic patterns, and better approaches** — all explained in plain English, without showing code.

## ✨ Features

- 📊 **Complexity Analysis** — Get instant Big-O estimates with simple explanations
- 🔍 **Pattern Detection** — Identify techniques like Two Pointers, Sliding Window, DP, etc.
- 💡 **Better Approaches** — Understand more efficient techniques conceptually
- 📋 **Submission Insights** — View verdict, runtime, memory, and percentile
- 🕐 **Analysis History** — Access previous analyses anytime
- 🎨 **Dark/Light Theme** — Matches your LeetCode experience
- 🔒 **Privacy First** — API key and analysis history stay stored locally

> Turn every LeetCode submission into a learning opportunity.
